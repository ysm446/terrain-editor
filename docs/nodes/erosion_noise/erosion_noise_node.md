# Erosion Noise ノード

方向性のある侵食風ノイズをハイトフィールドへ加える加工ノードです。大きな形状に細い谷筋や削れた表情を足すために使います。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | `Heightfield` |
| 出力 | `Heightfield` |

## 主な設定

| 設定 | 役割 |
| --- | --- |
| `Frequency` | ノイズの細かさ |
| `Octaves` | 重ねるノイズ階層数 |
| `Strength (%)` | 高さへ足し込む量 |
| `Direction Influence` | 入力地形の勾配方向をどれだけ使うか |
| `Valley Low` / `Valley High` | 低地側でノイズを抑える高さ範囲 |
| `Seed` | ノイズパターン |

## メモ

地形を物理的に侵食するノードではなく、見た目の侵食感を足す軽量なプロシージャル加工です。大局構造は `Shape` や `Heightmap Load` で作り、その後に薄く足すと使いやすいです。
