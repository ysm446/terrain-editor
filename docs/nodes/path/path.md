# Path

`Path` は、地形上の線や分岐構造を編集するためのガイドノードです。現段階では、後段の Heightmap / Mask 変換へ渡す前の編集データとして扱います。

## 使い方

- ノードネットワークのコンテキストメニューから `パス` > `Path` を追加します。
- `Path` ノードを選択すると、2D / 3D ビューが Path 編集モードになります。
- ビュー上をクリックするとポイントを追加します。
- 3D ビューで地形を拾えない場合は、XZ 平面上にポイントを追加します。
- 連続して追加したポイントは自動でエッジ接続されます。
- `Enter` キーで現在の連続線を確定します。確定後の次のクリックは、新しい線の始点になります。
- 既存ポイントをクリックすると選択します。選択後に別の場所をクリックすると、そのポイントから続きを伸ばせます。
- ポイント選択中に `W` キーを押すと移動ギズモを表示します。中心をドラッグするとカメラ平面に沿って移動し、軸の矢印をドラッグするとその軸に沿って移動します。
- ポイント間のエッジをクリックするとエッジを選択します。
- `Ctrl` を押しながらポイント間のエッジをクリックすると、その位置に新しいポイントを挿入してエッジを分割します。
- 選択中のポイントは `Del` キーで削除できます。接続しているエッジも同時に削除されます。
- 選択中のポイントはプロパティパネルで `Position (Vector3)`, `Width`, `Feather`, `Intensity`, `Height Offset`, `Height Mode` を確認・編集できます。

## データ構造

- ポイントは地形平面上の `x, z` と高さ情報、幅、フェザーを持ちます。
- エッジを分割して新しいポイントを作ると、幅とフェザーは両端ポイントから補間されます。
- 高さは、地形投影、地形からのオフセット、絶対高さへ拡張できる形にしています。
- エッジは接続元ポイント、接続先ポイント、幅、フェザー、enabled 状態を持ちます。

## 今後の予定

- ポイント移動、削除、分割。
- エッジ選択、切り離し、再接続。
- エッジごとの幅、フェザー、曲線、ノイズなどの編集。
- 稜線や川筋など、Path を使った Heightmap 生成ノード。
