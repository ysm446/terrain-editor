# Mask Height ノード

`Mask Height` は、入力 `Heightmap` の標高から `Mask` を生成するノードです。
指定した標高帯だけを取り出したり、入力地形の最低標高から最高標高までを 0..1 のグラデーションにしたりできます。

## 入出力

| 種類 | 名前 | 内容 |
| --- | --- | --- |
| 入力 | `Heightmap` | 標高を参照する地形 |
| 出力 | `Mask` | 標高範囲を 0..1 に変換したマスク |

## パラメータ

| 名前 | 既定値 | 内容 |
| --- | --- | --- |
| `Use Full Range` | off | 入力 `Heightmap` の最低標高を 0、最高標高を 1 として、標高全体をグラデーション化する |
| `Height Min (m)` | 0.0 | この標高より低い部分を黒にする |
| `Height Max (m)` | 1000.0 | この標高より高い部分を黒にする |
| `Feather (m)` | 0.0 | 標高帯の境界をメートル単位でぼかす |
| `Gamma` | 1.0 | 出力カーブ。1 未満で境界の弱い値を明るく、1 より大きいと中心の強い値を強調する |
| `Invert` | off | 出力を反転する |

`Use Full Range` が on のときは `Height Min (m)`、`Height Max (m)`、`Feather (m)` は使わず、地形全体の相対標高をそのままマスクにします。

## 用途

- 山頂や低地など、標高条件で素材や色を分ける。
- 地形全体の標高グラデーションを `Colorize` の `Gradient Mask` に使う。
- 雪、植生、岩肌の出る高さを制限する。
- `Mask Levels` と組み合わせて境界を締める。
- `Mask Blend` で `Mask Slope` や `Mask Curvature` と組み合わせる。
