# Mask Blend ノード

2 つの `Mask` を合成する加工ノードです。ノイズマスク同士を重ねたり、片方のマスクをもう片方で制限したりするために使います。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | `Mask A`, `Mask B` |
| 出力 | `Mask` |

## 主な設定

| 設定 | 役割 |
| --- | --- |
| `Blend Mode` | `Add` / `Multiply` / `Min` / `Max` |
| `Blend Intensity (%)` | `A` と合成結果の補間量 |

## メモ

片方の入力が未接続の場合は、接続されているマスクをそのまま通します。`Multiply` は領域の絞り込み、`Add` は領域の合成、`Min` / `Max` はしきい値的な合成に使いやすいです。
