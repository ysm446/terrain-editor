# Mask Levels ノード

`Mask Levels` は、入力 `Mask` の黒点、白点、中間調を調整して、後段で使いやすいマスクへ整えるノードです。

## 入力

- `Mask`: 調整するマスク。

## 出力

- `Mask`: level 調整後のマスク。

## パラメータ

- `Black Point (%)`: この値以下を黒にします。弱いマスク成分を切り落とすために使います。
- `White Point (%)`: この値以上を白にします。下げるほどマスクが早く飽和します。
- `Gamma`: 中間調のカーブです。`1` 未満で暗部を持ち上げ、`1` より大きいと強い部分だけを残します。
- `Invert`: 出力マスクを反転します。

## 使いどころ

- `Mask Curvature` の細かい線を締める。
- `Mask Fluvial` の川筋を太らせる、または主流だけに絞る。
- `Mask Noise` のコントラストを調整して、`Colorize` や `Snow` の制御に使いやすくする。
