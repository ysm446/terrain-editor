# Mask Slope ノード

`Mask Slope` は、入力 `Heightmap` の傾斜角から `Mask` を生成するノードです。
急斜面だけを取り出す、または `Invert` で平地だけを取り出す用途に使います。

## 入出力

| 種類 | 名前 | 内容 |
| --- | --- | --- |
| 入力 | `Heightmap` | 傾斜を計算する地形 |
| 出力 | `Mask` | 傾斜範囲を 0..1 に変換したマスク |

## パラメータ

| 名前 | 既定値 | 内容 |
| --- | --- | --- |
| `Slope Min (deg)` | 25.0 | この角度以下を黒にする |
| `Slope Max (deg)` | 60.0 | この角度以上を白にする |
| `Gamma` | 1.0 | 出力カーブ。1 未満で弱い斜面を明るく、1 より大きいと急斜面だけを強調する |
| `Invert` | off | 出力を反転する。平地マスクを作るときに使う |

## 用途

- 岩肌や崖を急斜面にだけ出す。
- 植生や雪を平地寄りに制限する。
- `Colorize` の `Mask` に接続して、斜面の色分けをする。
- `Mask Levels` と組み合わせて、斜面境界を締める。
