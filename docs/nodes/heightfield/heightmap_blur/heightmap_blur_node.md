# Heightmap Blur ノード

入力ハイトフィールドをぼかして、細かいノイズや段差をならす加工ノードです。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | `Heightfield` |
| 出力 | `Heightfield` |

## 主な設定

| 設定 | 役割 |
| --- | --- |
| `Radius (cells)` | ぼかし半径。大きいほど広い範囲をならします |
| `Strength (%)` | 元の高さとぼかし後の高さを混ぜる量 |
| `Iterations` | ぼかしの反復回数 |

## メモ

侵食後の D8 由来の階段状アーティファクトや、入力画像由来のピクセル感を弱める用途に向いています。強くかけすぎると稜線や谷筋も丸くなるため、仕上げでは小さめの半径と低めの強度から調整します。
