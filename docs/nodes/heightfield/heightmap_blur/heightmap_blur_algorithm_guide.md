# Heightmap Blur アルゴリズム入門

このメモは、`Heightmap Blur` ノードが内部で何をしているかを段階的に理解するための読み物です。
パラメータの詳細一覧は `heightmap_blur_node.md` にまとめています。

## まず何をするノードか

`Heightmap Blur` は、ハイトフィールドに対して**分離型ガウスぼかし**を適用するノードです。

主な用途は 2 つあります。

1. **D8 アーティファクトの除去**: `Multi-Scale Erosion` が作る水路はグリッドの 8 方向に制限されるため、小さな「階段状の段差」が残ります。軽くぼかすと自然に見えます。
2. **高周波ノイズの平滑化**: 入力ハイトマップに細かいノイズがある場合、浸食前に取り除いて安定した流路ネットワークを作るのに使います。

## 全体の流れ

1. ガウスカーネルの重みを事前計算する。
2. `Iterations` 回だけ、次の 2 パスを繰り返す。
   1. **水平パス**: 各行に沿ってガウス畳み込みを適用する。
   2. **垂直パス**: 各列に沿ってガウス畳み込みを適用する。
3. `Strength` で元の高さとぼかし後の高さをブレンドする。

分離型 (separable) で処理するため、2 次元ガウスを 1 次元 × 2 回に分解できます。
計算量は `O(n² × kernelRadius)` で、2 次元ループより大幅に軽くなります。

## 1. ガウスカーネルの計算

ガウス重みは次の式で計算します。

```text
w(x) = exp(-0.5 × (x / σ)²)
```

ここで `σ = radius × 0.5` です。

| 変数 | 意味 |
| --- | --- |
| `x` | カーネル中心からのオフセット (0, 1, 2, ..., kernelRadius) |
| `σ` | ガウス分布の標準偏差 |
| `w(x)` | 正規化前の重み |

重みは合計が 1 になるよう正規化されます。
中心ピクセル (`x = 0`) の重みが最も大きく、端へ行くほど減衰します。

## 2. 水平パス + 垂直パス (分離型畳み込み)

水平パスでは各行ごとに独立して処理します。

```text
temp[x, z] = Σ_{offset = -R}^{R} w(offset) × heights[clamp(x + offset, 0, n-1), z]
```

垂直パスでは水平パスの結果を縦方向に畳み込みます。

```text
blurred[x, z] = Σ_{offset = -R}^{R} w(offset) × temp[x, clamp(z + offset, 0, n-1)]
```

境界では `clamp` でグリッド端のピクセルを繰り返します (clamp-to-edge)。
これにより境界付近のアーティファクトを最小限に抑えます。

両パスとも `ParallelForRows` で行ごとに並列実行されます。

## 3. Strength によるブレンド

ぼかし後の高さを元の高さと `Strength` でブレンドします。

```text
result[i] = lerp(original[i], blurred[i], strength)
```

`Strength = 1.0` のとき完全なガウスぼかし、`Strength = 0.0` のとき変化なしです。

このブレンドは各 `Iterations` ループの最後に行います。
つまり `Iterations = 3, Strength = 0.5` は、「30% ぼかし → さらに 30% → さらに 30%」の積み重ねではなく、
毎回 50% ブレンドを 3 回繰り返したものになります。

## 4. Iterations による重ね掛け

`Iterations` を増やすと、1 回のぼかしでは届かない遠い範囲まで拡散します。
実効的なぼかし半径は `Radius × sqrt(Iterations)` に近いスケールで広がります。

代わりに `Radius` を大きくしても似た効果は得られますが、ループが 1 回で済む `Radius` 拡大の方が高速です。
`Iterations` は、計算コストを分散させながら累積的な効果を出したいときに使います。

## パラメータを直感で見る

| パラメータ | 直感的な役割 |
| --- | --- |
| `Radius (cells)` | カーネルの半径。大きいほど広い範囲をぼかす |
| `Strength (%)` | 元の高さとのブレンド率。100% で完全なぼかし |
| `Iterations` | 何回ぼかしを重ねるか。多いほど広く均される |

## よくある使い方

### Multi-Scale Erosion の後処理

D8 の 8 方向制限による段差を消すには、ごく軽いぼかしで十分です。

```
Radius: 1.0〜1.5
Strength: 15〜25%
Iterations: 1
```

地形の大局構造は保ちつつ、D8 のカクカクした流路だけを滑らかにします。

### 入力ハイトマップの前処理

高周波ノイズが強い入力を浸食前に均したい場合。

```
Radius: 2.0〜4.0
Strength: 50〜80%
Iterations: 1〜2
```

強くかけすぎると入力の起伏が失われ、浸食の流路パターンが乱れることがあります。

## 見た目が崩れるときの考え方

### 地形全体が均質な平面に近づいてしまう

`Strength` か `Iterations` が強すぎます。
`Strength` を 20〜30% 程度に下げるだけで、細部は残しながらアーティファクトを消せます。

### 端が不自然に高くなる (境界アーティファクト)

境界の `clamp-to-edge` の影響で端のピクセルが繰り返されるため、端に「壁」のように見えることがあります。
`Radius` を小さく抑えるか、入力ハイトマップ自体を端が 0 になるよう調整してください。
