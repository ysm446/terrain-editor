# Heightmap Load アルゴリズム入門

このメモは、`Heightmap Load` ノードが内部で何をしているかを段階的に理解するための読み物です。
パラメータの詳細一覧は `heightmap_load_node.md` にまとめています。

## まず何をするノードか

`Heightmap Load` はハイトフィールドパイプラインの**起点**となるノードです。
ディスク上のグレースケール画像ファイルを読み込み、ピクセル輝度を高さ値 (メートル) に変換して、後続の浸食・変形ノードへ渡します。

このノード自体は地形を変形しません。
出力は「読み込んだ画像をどう解釈するか」を決めるだけです。

## 全体の流れ

1. ファイルパスが変わった (またはパラメータが変わった) ときだけ再評価する。
2. Windows Imaging Component (WIC) でファイルを開き、グレースケールに変換する。
3. ピクセル輝度 [0, 1] をメートル値に変換する。
4. `Simulation Resolution` にリサンプルする。
5. `HeightfieldGrid` として後続ノードへ渡す。

## 1. 画像の読み込みと輝度変換

WIC は PNG / EXR / TIFF / BMP など多くのフォーマットを透過的に扱います。
内部では常に 32 bit float グレースケールへデコードします。

ピクセル値 [0, 1] を高さに変換する計算式は次の通りです。

```text
height = (pixelValue × relativeVertical / 100) × scale + offset
```

| 変数 | 意味 | デフォルト |
| --- | --- | --- |
| `pixelValue` | ピクセル輝度 (0 = 黒 = 最低, 1 = 白 = 最高) | — |
| `scale` | 地形の水平幅 (m)。縦横比の基準。 | 2048 m |
| `relativeVertical` | 水平スケールに対する最大高さの割合 (%) | 50% |
| `offset` | 全体の高さオフセット (m) | 0 m |

`Relative Vertical` が 50% ならば、白ピクセルの高さは `scale × 0.5` になります。
黒ピクセルは常に `offset` の高さです。

## 2. Simulation Resolution でリサンプル

読み込んだ画像は、`Simulation Resolution` で指定した解像度へバイリニアリサンプルされます。
元画像より低解像度に指定すると計算が速くなりますが、細部は失われます。
高解像度に指定すると計算コストが増え、元画像にない細部は補間で埋まります。

よく使うワークフロー:

- 試行錯誤中: `256` または `512` で高速評価。
- 最終出力: `1024` や `2048` でフル解像度評価。

浸食ノード (Multi-Scale Erosion など) はこの解像度をそのまま継承します。

## 3. HeightfieldGrid の初期化

読み込み後、グリッドのフィールドは次のように初期化されます。

| フィールド | 初期値 |
| --- | --- |
| `heights` | 画像から変換した高さ値 |
| `mask` | 0 (可視化チャンネル。後続ノードが書き込む) |
| `deposits` | 0 |
| `flows` | 0 |
| `age` | 0 |
| `terrainSizeMeters` | `scale` の値 |

## パラメータを直感で見る

| パラメータ | 直感的な役割 |
| --- | --- |
| `File` | 読み込む画像のパス |
| `Scale (m)` | 地形の水平幅。1 unit = 1 m なので、2048 m = 2.048 km |
| `Relative Vertical (%)` | スケールに対する最大高さの割合。50% = 高さは幅の半分 |
| `Offset (m)` | 全体を底上げまたは引き下げるオフセット |
| `Simulation Resolution` | 後段の計算に使う格子の解像度 |

## よくある問題

### 読み込んだ地形が平坦すぎる

`Relative Vertical` が低い場合、すべての高さが狭い範囲に圧縮されます。
50% 前後を基準に上げてみてください。

### 読み込んだ地形が歪んでいる

画像の縦横比が 1:1 でない場合、`Scale` で水平幅を合わせても縦横比がずれます。
現在は正方形グリッドのみ対応しています。

### 解像度を変えると浸食の見た目が変わる

`Simulation Resolution` は浸食の計算格子サイズを変えるため、結果に影響します。
`Multi-Scale Erosion` の `Use Multigrid` を有効にすると、解像度への依存が大幅に減ります。
