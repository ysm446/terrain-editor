# Heightmap Load ノード

画像ファイルからハイトフィールドを読み込む入力ノードです。グラフの地形生成パイプラインの起点として使います。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | なし |
| 出力 | `Heightfield` |

## 主な設定

| 設定 | 役割 |
| --- | --- |
| `File` | 読み込むハイトマップ画像のパス |
| `Scale (m)` | 読み込んだ画像がグローバル `Terrain Size (m)` 内で占める横幅と奥行き |
| `Relative Vertical (%)` | 横スケールに対する高さ倍率 |
| `Offset (m)` | 地形全体の高さオフセット |
| `Simulation Resolution` | 後段の侵食やマスク処理に渡す内部解像度 |

## メモ

画像はグレースケールの高さとして扱われます。地形全体の縦横サイズは設定タブの `Terrain Size (m)` で決まり、`Scale (m)` はその中で画像が占める実サイズです。

`File` はプロジェクト保存時に、可能な場合はプロジェクトファイルからの相対パスとして保存されます。プロジェクトと素材フォルダを一緒に移動した場合も、同じ相対関係であれば読み込み直せます。

`Scale (m)` が `Terrain Size (m)` より大きい場合は中央でクロップされます。小さい場合は中央に配置され、外側は高さ 0 になります。実サイズ感を保ちたい場合は、まず `Terrain Size (m)`、`Scale (m)`、`Relative Vertical (%)` を決めてから下流の侵食ノードを調整すると安定します。
