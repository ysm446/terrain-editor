# Crumbling アルゴリズムメモ

`Crumbling` は、崩落の発生、移動、堆積を分けて処理します。

## 処理の流れ

1. `Emission Mask` をサンプルし、明るい場所ほど崩落粒子が発生しやすくする。
2. 各粒子にサイズ、向き、形状、`Unique Mask` 値を決定論的に割り当てる。
3. `Heightmap` の局所勾配を読み、低い方向へ `Physics Count` 回まで移動する。
4. `Gravity` が高いほど勾配方向へ強く寄せ、低いほどランダムな散り方を残す。
5. `Spread` が高いほど進行方向から横へ逸らし、停止後に近すぎる岩片を軽く押し分ける。
6. 停止位置に `Rock Style` に応じた岩片形状を描き、最大寄与を `Heightmap` に加算する。
7. 岩片の形状を `Mask` に、岩片ごとのランダム値を `Unique Mask` に書く。

## 出力の意味

- `Heightmap` は入力地形に岩屑の高さを加算したものです。
- `Mask` は岩屑の形状と合成強度を表します。
- `Unique Mask` は岩片単位の色分けや材質ばらつきに使う値です。

## 現在の制限

- 初期実装は CPU 評価のみです。
- 粒子同士の本格的な剛体衝突や、岩片が削り取る侵食量はまだ扱っていません。現在は `Spread` に応じた簡易的な近接反発で重なりを緩和します。
- 堆積は停止位置の岩片加算を中心にした簡易モデルです。流下途中の細かい砂礫尾や、谷底での厚い堆積は今後の改善候補です。
