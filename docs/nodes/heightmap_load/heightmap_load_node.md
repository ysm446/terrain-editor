# Heightmap Load ノード

画像ファイルからハイトフィールドを読み込む入力ノードです。グラフの地形生成パイプラインの起点として使います。

## 入出力

| 種類 | 内容 |
| --- | --- |
| 入力 | なし |
| 出力 | `Heightfield` |

## 主な設定

| 設定 | 役割 |
| --- | --- |
| `File` | 読み込むハイトマップ画像のパス |
| `Scale (m)` | 地形の横幅と奥行き。1 unit = 1 m として扱います |
| `Relative Vertical (%)` | 横スケールに対する高さ倍率 |
| `Offset (m)` | 地形全体の高さオフセット |
| `Simulation Resolution` | 後段の侵食やマスク処理に渡す内部解像度 |

## メモ

画像はグレースケールの高さとして扱われます。実サイズ感を保ちたい場合は、まず `Scale (m)` と `Relative Vertical (%)` を決めてから下流の侵食ノードを調整すると安定します。
