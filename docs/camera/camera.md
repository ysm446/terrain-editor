# カメラ

Terrain Editor の `Camera` カテゴリは、ビューポートで地形をどう見るかを調整するための設定です。ここで扱う値は表示用であり、ノード評価、内部 Heightfield / Mesh データ、OBJ エクスポートには影響しません。

## 基本方針

- 地形制作中の見やすさを優先する。
- 可能な範囲で現実のカメラに近い単位を使う。
- 表示表現はビューポート専用にし、生成データや保存形式の意味を変えない。
- スクリーンショットや見た目確認では、撮影表現として使える余地を残す。

## ビュー操作

- `FOV`: 垂直画角です。小さいほど望遠、大きいほど広角になります。
- `焦点距離 (mm)`: FOV と連動するレンズ焦点距離です。35mm フルサイズ相当の感覚で扱います。
- `Distance`: 注視点からカメラまでの距離です。最大 100000m まで指定できます。
- `Yaw`: 水平方向の回転です。
- `Pitch`: 垂直方向の回転です。
- `F`: カメラを初期視点へ戻します。`Reset View` と同じ操作です。初期視点は yaw / pitch ともに約 30 度で、距離は現在の `Terrain Size (m)` から全体が収まりやすい値を計算します。

`FOV` と `焦点距離 (mm)` は同じ見え方を別の単位で操作するための値です。片方を変えると、もう片方も対応する値に変換されます。

## 太陽

`太陽と影` の `Sun Mode` は、`Manual` と `Date Time` を切り替えます。`Manual` では方位角と高度を直接指定し、`Date Time` では緯度、経度、UTC Offset、月日、時刻から簡易的な太陽位置を計算します。方位角は 0 度が南 (`Z+`)、90 度が東 (`X+`) です。

## Depth of Field

`Depth of Field` は被写界深度の表示設定です。チェックボックスで有効化し、F 値、フォーカス距離、センサー高さ、最大ぼけ量を調整します。ボケ量に使う焦点距離は、Camera の `焦点距離 (mm)` と同じ値です。

フォーカス距離は数値入力のほか、3D ビューポート上の地形を `Ctrl+クリック` して設定できます。`Ctrl` を押している間は十字カーソルと地形上のターゲットが表示され、クリックした地点までのカメラ前方距離が `フォーカス距離 (m)` に反映されます。Camera タブの `フォーカスを選択` ボタンを押した場合も同じピック操作になり、`Esc` または右クリックでキャンセルできます。

詳しくは [depth_of_field.md](depth_of_field.md) を参照してください。

## 保存

カメラ設定はアプリ設定とプロジェクト設定に保存されます。プロジェクトを開き直したときに、ビューと撮影表現を再現しやすくするためです。

プロジェクトファイルでは、`viewport` に `yaw`、`pitch`、`fovDegrees`、`orbitDistance`、`pan` を保存します。被写界深度の値は `settings.preview` に保存します。DOF の焦点距離は個別保存せず、`viewport.fovDegrees` から Camera の焦点距離として復元します。

古いプロジェクトに `viewport.zoom` が保存されている場合、その値は読み込み時に無視されます。3D ビューポートの見え方は `Distance` と `FOV` / `焦点距離 (mm)` で決まります。
## Miniature DOF

`Depth of Field` の `Miniature` をオンにすると、地形をミニチュア撮影風に見せるために DOF のぼけ量を強調できます。`Miniature Scale` はその倍率で、値を大きくすると焦点幅が浅く見えます。オフの場合は従来通りの DOF 計算です。
