# Water Surface

## 将来の River / Lake との統合方針

現在の `Water Surface` は、ビューポート上で水面を確認するための水平水面表示だが、シェーダー側の水表現は将来の `River` / `Lake` ノードにも共通利用できる水レンダリング基盤として扱う。

基本方針は、`River` / `Lake` ノードが水の形状と物理的な入力を作り、表示側は共通の水マテリアルで描画すること。これにより、湖、貯水した谷、川、河口が別々の見た目にならず、同じ世界の水としてなじむ。

将来の水系ノードが出すとよい情報:

- `Water Surface Mask`: 水が存在する領域。
- `Water Height`: ピクセルまたは頂点ごとの水面高さ。湖ではほぼ一定、川では上流から下流へ勾配を持つ。
- `Water Depth`: 水面と地形の差。透明度、色の濃さ、岸際フェード、断面表示に使う。
- `Flow Direction`: 川の流れ方向。法線波、泡、流れ模様の移動方向に使う。
- `Flow Speed`: 流れの速さ。波の伸び、泡の発生、反射の乱れに使う。
- `Turbidity / Opacity`: 水の濁りや吸収距離。現在の `Opacity` と同じ概念として扱う。
- `Foam / Shore Wetness Mask`: 岸、急流、段差、滝、浅瀬の泡や濡れ表現に使う補助マスク。

レンダリング側で共通化したい要素:

- 水色、濁り、深度による透明度。
- フレネル反射、太陽スペキュラー、必要に応じた SSR。
- スクリーンスペース・リフラクション。
- 岸際の最低アルファと地形接触フェード。
- 断面表示時の水の厚み、にじみ、深度色。

現在の水平水面は `waterLevelParam` ひとつで高さを決めている。川では水面高さが場所ごとに変わるため、将来的には `waterHeightTexture` または水面メッシュの頂点高さを入力し、シェーダーでは現在の `waterLevelParam` の代わりにピクセル/頂点ごとの水面高さを使う。

川の水面は、単なる水平板ではなく、流路マスクに沿った水面メッシュまたは水高さフィールドとして生成する。表示シェーダーは湖と川で分けず、入力の違いだけで同じ水マテリアルを使う。川だけに必要な流れ方向の法線アニメーション、泡、急流表現は、共通シェーダーの追加入力として拡張する。

当面の実装順の候補:

1. 現在の水面シェーダーを `WaterMaterial` として整理し、水平水面表示から独立させる。
2. 湖は `Water Surface Mask` と一定の `Water Height` を入力する形へ移行する。
3. 川は流路マスク、勾配付き `Water Height`、`Flow Direction`、`Flow Speed` を生成する。
4. SSR、屈折、透明度、スペキュラーは共通処理として維持する。ただし SSR は画面内情報に依存するため、品質オプションとして扱う。
5. 川専用に泡、流れ模様、岸濡れマスクを追加する。

`Water Surface` は、地形データを変更せずに 3D ビューポートだけへ水面を重ねる表示機能です。

## 目的

- 湖、海、貯水した谷のような水域を、ノード実装前に見た目として確認する。
- 断面表示と組み合わせ、水位がどの高さまで入るかを読みやすくする。
- 将来の `Lake` / `River` ノードで使う水面表示の土台にする。

## パラメータ

- `Water Surface`: 水面表示のオン / オフ。
- `Water Level (m)`: 水面の高さ。0 m 以上で、地形キャンバス全体に水平な水面を置く。
- `Opacity`: 水の濁り / 吸収の強さ。0 では遠くまで透き通り、1 では短い距離で不透明に近づく。反射とスペキュラーは透明度とは別に残る。
- `Water Color`: 水の基本色。水そのもののペンキ色ではなく、吸収と濁りで残る色として扱う。デフォルトは低彩度の青緑 (`0.04, 0.24, 0.36`) で、シェーダー側で波模様、屈折、フレネル、スペキュラー反射を加える。
- `Waves Scale (m)`: 水面法線の主波長。大きいほど波長が長く穏やかな海面になる（デフォルト 24.0 m）。
- `Reflection Strength`: 空反射と反射全体の強さ。0 で反射なし、1 が標準、2 で強め。
- `Screen Space Reflections`: 画面内に描かれている地形を追加で水面へ反射する。画面外や隠れた地形は反射できないため、自然さを優先する既定状態ではオフ。
- `Refractive Index`: フレネル反射用の屈折率。Schlick 近似で Fresnel F0 を算出する。1.0 = 反射なし、1.33 = 水相当、2.0 = ガラス相当（デフォルト 1.33）。
- `Refraction Strength`: スクリーンスペース屈折の歪み量。0 で屈折なし、1 が標準、2 で強め。
- `Refraction Blur`: 屈折した背景のにじみ量。主に断面側壁で効き、0 でシャープ、1 で強めにぼかす。

## 水面の構成

### 上面

水位に配置された水平メッシュを描画する。上面メッシュはハイトフィールドでクリップし、水位より地形が低い領域だけを三角形化する。

- **波法線**: `Waves Scale` を主波長として、方向と波長の異なる複数の正弦波の勾配を合成した擾乱法線。地形スケールでは 20〜80 m 程度が自然に見えやすい。
- **フレネル反射**: `Refractive Index` から `F0 = ((n-1)/(n+1))²` を導出し Schlick 近似を適用。
- **空反射**: 反射方向 (カメラの Y 成分を反転した方向) で地平線色と天頂色を補間。
- **地形反射**: ハイトフィールドテクスチャから高さベースの地形色を近似し、視差オフセット付きでブレンド。浅い箇所ほど地形反射が強く、深い箇所は空反射が支配する。
- **スクリーンスペース・リフラクション**: 水面描画前のシーン色をコピーし、水面法線でスクリーン UV を少し歪ませてサンプルする。透明で浅い水ほど背後の地形色が屈折して見え、濁りや水中距離が増えるほど水色側へ戻る。
- **スクリーンスペース・リフレクション (SSR)**: `Screen Space Reflections` が有効なときだけ、水面描画前のシーン深度とシーン色をコピーし、水面上面だけ反射方向へ短くレイマーチする。画面内でヒットした地形色は水面反射へ薄く混ぜ、ヒットしない場所や画面外は空反射と高さベースの地形近似へ戻す。
- **太陽スペキュラー**: 平面水面で見た太陽反射位置を細めの帯として使い、その範囲内に低周波寄りの波法線で控えめなハイライトと小さなグリントを乗せる。
- **端の反射処理**: 地形近似反射だけは外周の輝線を避けるために端で弱める。太陽スペキュラーは外周でも減衰させず、水面上で途切れないようにする。
- **水深による透明度**: 上面はカメラ方向にレイマーチし、水面から見えている地形へ当たるまでの水中距離を主に使う。鉛直水深は岸際や反射の補助に使い、斜め視点で真下の地形だけに引っ張られないようにする。`Opacity` は内部で透明距離へ変換し、低い値では遠くまで透け、高い値では短い距離で濁る。水と地形の境界が途切れて見えないよう、薄い水と岸際にも最低限のアルファを残す。

### 断面 (側壁)

Water Level が 0 m より大きい場合、地形ボックスの 4 辺に垂直なクワッドを描画する。下辺はハイトフィールドの外周高さに沿う。

- **厚みによる不透明度**: 水面とハイトフィールドの距離が近い薄い場所は透明になり、厚みがある場所ほど不透明へ近づく。距離に対する濁り方は `Opacity` で調整する。
- **地形接触フェード**: 断面側壁のうちハイトフィールドに近い下端は透明寄りにし、水面側へ離れるほど厚みベースの不透明度が出る。接触線には最低限のアルファを残し、断面に隙間が出ないようにする。
- **断面リフラクション**: 水面描画前のシーン色を側壁法線と低周波の揺らぎで少し歪ませ、軽いブラーを混ぜる。薄い水では背後の地形色がにじみ、厚い/濁った水では水色側へ戻る。
- **深度シェーディング**: 浅い部分は明るく彩度を抑えた色、深い部分は暗くわずかに青みを加えた色でブレンドする。
- **ライティング**: 太陽方向との half-Lambert 照明を加える。

### 深度テストと描画順

- DepthWriteMask = ZERO / DepthFunc = LESS_EQUAL で不透明な地形の上にアルファブレンドされる。
- 地形断面 (セクション壁) との重なりは深度テストで正しく解決される。
- 水面上面と水の断面側壁は同じ水メッシュ内で描くが、透明ブレンドで側壁が上面のスペキュラーを上書きしないよう、側壁を先、上面を後に描く。

## 制限と今後の候補

- 表示専用で、Heightfield / Mesh / OBJ エクスポートには反映しない。
- SSR は画面内に描かれている地形だけを反射できる。画面外や深度ヒットしない場所は天空色と高さベースの地形近似で補う。自然さと安定性を優先する場合は `Screen Space Reflections` をオフにする。
- マスクや Heightfield の値には影響せず、あくまで最終表示だけを加工する。

## 保存

水面設定はアプリ設定 (`data/app_settings.json`) とプロジェクトファイル (`.terrainproj`) の両方に保存される。保存対象は `waterEnabled`、`waterLevelMeters`、`waterOpacity`、`waterColor`、`waterWavesScale`、`waterReflectionStrength`、`waterSsrEnabled`、`waterRefractiveIndex`、`waterRefractionStrength`、`waterRefractionBlur`。
