# ゴール

このファイルは、Terrain Editor で目指す到達点を共有するための場所です。

## 長期ゴール

- 地形生成ノードを組み合わせて、実用的な地形制作フローを作れるようにする。
- 主要なノードを安定してプレビュー、保存、再読み込みできるようにする。
- CPU と GPU の実装差を把握しながら、重い処理を段階的に高速化する。
- ドキュメントを残し、あとから設計意図と進捗を追えるようにする。

## 中期ゴール

- 既存ノードの品質、速度、UI の使いやすさを継続的に改善する。
- 追加したノードや表示機能を `docs/nodes/` と changelog に記録する。
- 重要な仕様変更は、この共有スペースで事前に整理する。
- 崩落、岩屑、堆積など、地形の物理的な説得力を増すノードを増やす。
- マスク加工系ノードを充実させ、地形生成ノードの制御に使いやすい中間マスクを作れるようにする。
- カラーランプやグラデーションを扱うノードを追加し、地形の色作りもノードグラフ内で進められるようにする。

## 判断基準

- ユーザーが見て分かる改善か。
- 既存プロジェクトとの互換性を守れるか。
- ノードグラフとして自然に組み合わせられるか。
- マスク、ハイトマップ、ノード出力の意味が分かりやすいか。
- 色、マスク、地形の関係を直感的に編集できるか。
- 将来の自分たちが読み返して意図を理解できるか。
