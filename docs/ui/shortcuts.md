# ショートカット

Terrain Editor のキー操作とマウス操作の一覧です。同じ内容はアプリ内でも `表示 > ヘルプ` から表示できます (ウィンドウの位置とサイズは `imgui.ini`、表示のオン / オフは `data/app_settings.json` に保存されます)。

共通のルールは次の 2 つです。

- ビューポート系の操作は、マウスがそのビュー (3D ビュー / 2D ビュー) の上にあるときだけ効きます。
- テキスト入力中 (数値フィールドや名前の編集中) は、単独キーのショートカットは無効になります。

## ファイル / 編集

| キー | 動作 |
| --- | --- |
| `Ctrl+S` | プロジェクトを保存します。未保存の新規プロジェクトでは保存ダイアログが開きます。 |
| `Ctrl+Z` | 元に戻します。 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | やり直します。 |
| `F12` | コンテンツ部分のスクリーンショットを保存します。詳細は [screenshot.md](screenshot.md) を参照してください。 |

## 3D ビュー

| キー / マウス | 動作 |
| --- | --- |
| `Alt+左ドラッグ` | カメラを回転します。 |
| `Alt+右ドラッグ` / `Alt+中ドラッグ` | カメラを平行移動 (パン) します。 |
| `Alt+ホイール` | ズームします。 |
| `A` | カメラを初期視点へ戻します。`Reset View` と同じ操作です。 |
| `O` | カメラの自動回転をオン / オフします。 |
| `D` | Depth of Field をオン / オフします。 |
| `C` | ボリューム雲の描画をオン / オフします。 |
| `L+左ドラッグ` | 太陽の方位角と高度を直接調整します。ドラッグ中は太陽方向ギズモを表示します。 |
| `F` 押しながら左クリック | Depth of Field のフォーカス距離を、クリックした地点までの距離に設定します。`Esc` で取り消します。 |

カメラと太陽の詳細は [../camera/camera.md](../camera/camera.md)、Depth of Field は [../camera/depth_of_field.md](../camera/depth_of_field.md) を参照してください。

## 2D ビュー

| マウス | 動作 |
| --- | --- |
| `Alt+ホイール` | ズームします (カーソル位置を基準にします)。 |
| `Alt+ドラッグ` | 平行移動 (パン) します。左 / 右 / 中ボタンのどれでも動きます。 |
| `Alt+ダブルクリック` | 2D ビューのズームとパンを初期化します。 |

## ノードネットワーク

| キー | 動作 |
| --- | --- |
| `Ctrl+C` | 選択したノードをクリップボードへコピーします。 |
| `Ctrl+V` | ノードを貼り付けます。貼り付け位置は現在のビュー中心です。 |
| `Delete` | 選択したノードとリンクを削除します。 |

## パス編集

`Spline` などのパスノードを選択している間、3D ビューと 2D ビューで有効になります。

| キー / マウス | 動作 |
| --- | --- |
| `左クリック` | パスの点を追加します。既存の点や辺の上ではその要素を選択します。 |
| `Ctrl+左クリック` | 辺の上に点を挿入します。 |
| `W` | 選択した要素の移動ギズモを表示します。 |
| `Enter` | 現在のセグメントを確定し、続きの追加を終了します。 |
| `Delete` | 選択した点または辺を削除します。 |

## 補足

- `ファイル` メニューの `新規` / `開く` には `Ctrl+N` / `Ctrl+O` と表示されていますが、これはメニューのラベルだけで、現状キー操作は割り当てられていません (単独の `O` はカメラの自動回転です)。
- ショートカットのカスタマイズ (`設定 > ショートカット設定`) は未実装です。
