# スクリーンショットと通知

`F12` キーで、アプリのコンテンツ部分を PNG として保存します。撮影範囲はウィンドウのクライアント領域そのもので、タイトルバー、ウィンドウ枠、影は含みません。

## 保存先とファイル名

- プロジェクトを保存済みの場合: プロジェクトファイルと同じ階層に作る `screenshots` フォルダー
- 未保存の場合: 実行時のカレントディレクトリ直下の `screenshots` フォルダー
- ファイル名: `terrain_editor_screenshot_YYYYMMDD_HHMMSS.png`

保存先の決定は `ScreenshotDirectoryForProject` (`src/PathUtils.cpp`) が担当します。

## 撮影方式 (バックバッファ読み戻し)

画面 (デスクトップ) からの切り出しではなく、スワップチェーンのバックバッファを直接読み戻して PNG 化します。

1. `RenderFrame` で ImGui の描画コマンドを積んだあと、バックバッファを `RENDER_TARGET` から `COPY_SOURCE` へ遷移させる。
2. `GetCopyableFootprints` で求めたフットプリントに合わせて READBACK バッファを確保し、`CopyTextureRegion` でコピーする。
3. `Present` 後にフェンスを待ち、READBACK バッファを `Map` する。
4. `SaveRgbaScreenshot` (`src/screenshot_capture.cpp`) が RGBA8 を BGRA へ詰め直し (行パディングもここで落とす)、WIC で PNG エンコードする。

この方式の利点は次の 3 つです。

- タイトルバー、ウィンドウ枠、影が入りません。
- 手前に別のウィンドウが重なっていても、ウィンドウが画面外へはみ出していても、描画された内容がそのまま保存されます。
- ディスプレイの拡大率 (DPI スケーリング) の影響を受けません。アプリは DPI-unaware なので画面上は Windows によって拡大表示されますが、保存される PNG は常にクライアント領域と同じピクセル数です。

撮影を要求したフレームは通知トーストを描画しないため、直前の通知が写り込むこともありません。

## 解像度とウィンドウサイズ

保存される PNG のサイズは、クライアント領域 (= スワップチェーンのバックバッファ) のサイズと一致します。狙った解像度で撮りたい場合は `表示 > ウィンドウサイズ` からプリセットを選びます。

| プリセット |
| --- |
| 1280 x 720 (HD) |
| 1600 x 900 |
| 1920 x 1080 (Full HD) |
| 2560 x 1440 (WQHD) |
| 3840 x 2160 (4K) |

- メニューには現在のコンテンツサイズも表示されます。
- `AdjustWindowRect` でウィンドウ枠とタイトルバーの分を外側へ広げるため、クライアント領域はちょうど指定サイズになります。
- 画面より大きいサイズも指定できます。ウィンドウは画面からはみ出しますが、バックバッファ読み戻しなので保存される PNG は欠けません (例: 125% スケーリングの 1920x1080 ディスプレイでも、1920x1080 プリセットで 1920x1080 の PNG が得られます)。
- 選んだサイズは `data/app_settings.json` の `window` に保存され、次回起動時にも復元されます。

## 通知トースト

保存すると、画面右下に通知が表示されます。

- 内容: 「スクリーンショットを保存しました (幅 x 高さ)」、ファイル名、「クリックで保存先フォルダーを開く」
- 左クリック: Explorer で保存先フォルダーを開き、そのファイルを選択状態にします
- 右クリック: 開かずに閉じます
- 約 6 秒でフェードアウトします。マウスを乗せている間は消えません
- 複数同時に出た場合は右下から積み上げ、最大 4 件まで表示します

トーストは `PushToast` / `DrawToastNotifications` (`src/main.cpp`) の汎用機構で、スクリーンショット以外の通知にも使えます。

## 関連ファイル

- `src/screenshot_capture.h` / `src/screenshot_capture.cpp`: RGBA ピクセル列の PNG 保存
- `src/main.cpp`: `BeginScreenshotReadback` / `FinishScreenshotReadback` (読み戻し)、`PushToast` / `DrawToastNotifications` (通知)、`SetWindowClientSize` (ウィンドウサイズ)
- `src/PathUtils.cpp`: 保存先フォルダーの決定
